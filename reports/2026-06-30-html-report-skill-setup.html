Quy tắc chất lượng skill ép buộc

Mỗi report bắt buộc dùng ≥ 3 yếu tố tương tác. Có thể tóm gọn:

$$\text{report đạt chuẩn} \iff \sum_{\text{yếu tố tương tác}} 1 \;\ge\; 3$$

  • 1 file duy nhất, CDN-only, không build step
  • Responsive (chạy tốt ở viewport 375px) · Dark mode có toggle lưu localStorage
  • <title> + meta description + OG tags · sticky TOC nếu >2 section
  • Tôn trọng prefers-reduced-motion · không màu hardcode light-only · không style="" inline

Xử lý sự cố & ghi chú

Lệnh dùng python3 nhưng máy mình là python

Trên Windows, Python cài user-scope thường chỉ tạo python.exe. SKILL.md ghi ví dụ python3; khi chạy thật, Claude dùng đường dẫn đầy đủ tới python.exe nên không vướng. Nếu tự gõ tay, thay python3 bằng python.

git push báo lỗi xác thực

Máy này dùng Git Credential Manager và đã có credential GitHub sẵn nên push chạy im lặng. Nếu sau này hết hạn, lần push tiếp theo GCM sẽ bật cửa sổ đăng nhập lại — approve một lần là xong.

Muốn đổi giao diện mặc định của report

Sửa .claude/skills/html-report/templates/base.html (font, màu, thư viện) hoặc SKILL.md (hành vi của Claude: ưu tiên thư viện nào, ngưỡng chất lượng). SKILL.md là đòn bẩy mạnh nhất.

Pages báo 404 ngay sau khi push

GitHub Pages cần ~1 phút để build sau mỗi lần push. Đợi rồi refresh. Repo này Pages đã bật sẵn nên các report mới chỉ chờ build.
